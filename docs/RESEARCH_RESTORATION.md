# 기존 연구 결과 표시 복원

공개 통계 화면에 `web/data/risk_snapshot.json`의 14개 지방청 연구 결과를 연결한다. 생성일, 점수, 분류를 그대로 보존하며 새로운 예측이나 연도별 재계산은 하지 않는다. 공동 관할은 기존 지방청 연결을 사용하고, 복수 지방청 지역은 각 점수를 별도로 표시한다.

빌드 검증은 원본 해시, 지방청 누락, 유한한 0–100 점수, 가중합(인력 40%·감염병 40%·물자 20%), 분류 경계를 확인한다. 이 검증은 계산 결과 보존 여부만 검증하며 지표의 타당성을 보증하지 않는다.

기존 계산에는 기간·단위 미확인 질병청 수치의 합산과 임의 정규화가 포함되어 있다. 물자 점수는 전국 공통값이며 지역 업체 소재지 집계와 구분한다. 화면에 이 한계와 고정 스냅샷임을 표시한다. 실제 위험 확률이나 검증된 예측값으로 제시하지 않는다.

대응 추천 영역은 공개 자료 대조, 병무 행정 처리 기록 확인, 공식 보건 안내 확인, 계약 중복·집계 검토 등 일반 행정 점검을 제공한다. 기존 가중 기여순으로 표시하되 실제 병력 재배분, 전시근로역 활용, 전략물자 비축 확충 등 운용 조치는 포함하지 않는다. 실제 인원 배치·징집 적합성·조달 결정을 자동화하지 않는다.

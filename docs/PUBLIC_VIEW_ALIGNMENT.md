# TriGuard 공개 조회 화면 정리 (2026-09-24)

Vercel은 동일 저장소의 공개 조회·공유 화면이며 Streamlit 분석 엔진과 기능 동등성을 주장하지 않는다.

- 첫 화면에 프로젝트 역할을 설명하고 선택 권역별 자료 기간·범위·연결 상태를 제공한다.
- 병역판정검사 연도와 기관별 독립 기간, 보관 연구 결과의 생성 시각을 구분한다.
- 현재 조회 자료와 과거 연구 입력 파일의 동일성은 확인되지 않았음을 표시한다.
- 권역 분석·상세·보완 안내로 바로 이동할 수 있다. 전국 공통 자료는 지역 자료로 오인하지 않도록 안내한다.
- 보고서 병역판정검사 표를 항목별 세로 배치로 바꾸고 숫자 줄바꿈을 막는다. 좁은 표는 가로 스크롤을 지원한다.
- 점수 재계산이나 군사운용 추천 엔진 연결을 추가하지 않는다. 단위·기간이 누락된 질병청 자료는 미확인 상태를 유지한다.

검증: 기존 지역 연결 테스트에 기관별 독립 기간·공동 관할·미연결 표시 회귀 검사를 추가했다. 실제 휴대전화의 PDF 저장 동작은 별도 확인 대상이다.

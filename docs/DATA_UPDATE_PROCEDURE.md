# 자료 갱신·미확인 항목 검토 절차

1. 새 자료와 함께 공식 URL, 조회 조건(기간·단위·지역·질병/항목), 내려받은 날짜, 열 제목이 포함된 원본을 보관한다.
2. 기존 보관 자료를 교체하기 전에 행·열 변화와 빈 셀, 기간별 의미, 지역 명칭을 대조한다. 단순 파일명 날짜를 공식 기준일로 취급하지 않는다.
3. `python3 scripts/build_public_statistics.py`로 원자료·다운로드·기관별 해시 대조를 실행한다. ARI 파일 해시가 바뀌면 기존 검증 메타데이터를 재사용하지 않고 공식 열 순서를 다시 대조한다.
4. `python3 -m unittest discover -s tests -p test_public_statistics.py` 및 `node --test tests/test_data_review.cjs tests/test_statistics_tools.cjs tests/test_dashboard_state.cjs`를 실행한다.
5. 미리보기에서 지역 선택, 공유 링크 복원, 자료 선택, 빈 값 표시, 보고서 미리보기를 검증한다. 기기별 파일 업로드와 실제 PDF 저장은 별도로 확인한다.
6. 변경한 파일·조회 조건·검증 결과를 PR에 적고 공개 배포 상태를 확인한다. 원본 변경만으로 보관 연구 점수를 갱신했다고 설명하지 않는다.

## 현재 미확인 항목
- 지역별·질병별 감염병: 다운로드 당시 조회 기간, 발생수/발생률 단위, 수치 열의 실제 제목.
- 인플루엔자: 모든 절기의 열별 주차 대응 및 보관 CSV의 수치 단위. 첫 절기만 대조한 결과를 전체 절기의 근거로 쓰지 않는다.
- 보관 연구 결과: 생성일과 결과 파일 해시는 있으나 입력 파일별 당시 해시 목록은 없다. 현재 연결 파일을 당시 입력 파일로 소급 인증하지 않는다.

공식 페이지 재확인(2026-09-20): https://dportal.kdca.go.kr/pot/is/st/influ.do 및 https://dportal.kdca.go.kr/pot/is/rginEDW.do . 현재 페이지의 선택 조건만으로 과거 CSV 조건을 복원할 수 없어 미확인 상태를 유지했다.

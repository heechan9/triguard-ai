# Streamlit / Vercel 기능 대조

Vercel은 `public-statistics`의 정적 화면이며 Streamlit `app.py`를 실행하지 않는다.

## 구현된 기능
- 5개 기관 12종 공개자료 연결, 원본 출처·기간 표시, 공동 관할 연결
- 기존 연구 스냅샷의 지역 점수와 세 구성요소 표시 및 CSV 내보내기 (재계산 없음)
- 병역판정검사 6개 원자료 항목별 전국 지방청 비교, 전국 원본 합계, 선택 지방청 연도별 추이와 CSV
- 기관 원자료 검색 결과 CSV 내보내기
- 브라우저 내부 CSV 검토: UTF-8/CP949, 열 선택, 누락·비수치 개수, 최솟값·최댓값·평균, 처음 20행 표·차트, 자료·요약 CSV
- 실제 지역과 분리된 가상 행정 처리량 실습: 재현 가능한 시드와 기준 건수·변동폭

## 기존 Streamlit과 여전히 다른 기능
- 실제 지역의 병력운용 위험 재계산, 위험 순위·우선 대응 권역 자동 선정, 운용 조치 추천은 확장하지 않는다.
- 기존 연구 점수 기반 색상지도·전국 등급 집계·ML 분류·이상 탐지는 이 변경에서 구현하지 않았다.
- CSV 불러오기는 원자료 검토용이며 기존 연구 점수와 연결되지 않는다. 시뮬레이션도 기존 위험평가 시뮬레이션과 다르다.
- 상세 계산 근거는 보존 스냅샷의 세 구성요소와 고정 가중치까지 제공한다. 원래 엔진의 모든 하위 지표와 AI 결과를 복원한 것은 아니다.

## 검증 경계
수치 조회·CSV 파싱·파일 내보내기의 검증은 예측 타당성이나 정책 효과를 증명하지 않는다. 현재 화면을 Streamlit 전체 복원으로 설명하지 않는다.

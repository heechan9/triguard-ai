# 파일 내보내기 검증 (2026-09-20)

## 실제 CSV 파일
- 브라우저 파일 선택기로 UTF-8 및 CP949 한글 CSV를 읽었다. UTF-8 4행은 수치 2개, 빈 셀 1개, 비수치 1개로 표시됐고, CP949 2행은 42와 0으로 표시됐다.
- 브라우저 다운로드와 동기화된 `triguard-local-data.csv`를 실제로 열어 입력 CSV와 모든 셀이 같은지 비교: 일치. 쉼표가 포함된 1,200, 0, 빈 셀, 한글 비수치 문자열 보존.
- 저장된 `triguard-archived-research.csv` 14개 지방청 통합 점수를 원본 `web/data/risk_snapshot.json`과 비교: 전부 일치. 기준일과 보관 결과 구분 포함.
- 자동화의 다운로드 완료 이벤트가 시간 초과되어도 파일은 실제 저장돼 있었다. 이벤트 실패를 파일 저장 실패로 단정하지 않는다.

## PDF 레이아웃
- 운영 화면에서 서울·2025년 지역 보고서 HTML을 추출해 현재 인쇄 CSS로 WeasyPrint 렌더링.
- 검증 환경에 한글 폰트가 없어 검증용 Noto Sans CJK KR을 별도 로드했다. 웹에 외부 폰트 의존성을 추가한 것은 아니다.
- 6페이지 모두 시각 검토. 한글, 수치, 표 행, 원본 출처 목록을 확인했다.
- 전체 테이블에 상속되던 nowrap을 보고서에서 해제하고 고정 표 레이아웃·줄바꿈 적용. 긴 제목의 인쇄 잘림 가능성을 줄였다.
- 이 검증은 Chrome/Android의 실제 인쇄 대화상자 또는 기기 PDF 저장을 검증한 것이 아니다. 해당 검증은 아직 남아 있다.

## 메타데이터
질병청 미확인 열의 단위·기간과 보관 연구 결과의 생성 당시 입력 해시는 새 증거가 없어 미확인 상태를 유지한다. 파일 저장 검증이 지표 타당성을 입증하지 않는다.

# 기관 자료 메타데이터 확인 기록

## 2026-09-20 확인 및 수정

국내조달 CSV에는 `대표업체주소`가 있다. 기존에 모든 방위사업청 파일의 지역 연결이 불가능하다고 설명한 것은 잘못이다. 국내조달은 주소의 첫 시·도 표기로 집계할 수 있으며, 국외조달·입찰참여 파일에는 주소 열이 없다.

- 국내조달 43,112행 = 시도 분류 43,092행 + 미분류 20행.
- 대구 1,333행, 경북 1,492행. 계약 변경·반복 기록을 포함하며 고유 계약 수가 아니다.
- 강원특별자치도/강원도 및 전북특별자치도/전라북도를 지도 이름에 맞춰 정규화한다.
- `충남대전시`, 구 이름만 있는 주소, 가림/숫자 표기는 추측하지 않고 미분류한다.
- 업체 소재지는 납품지나 군사 배치 위치가 아니다. 개인 이름·주소 전문·개별 계약 정보를 생성 JSON에 넣지 않는다.
- 병무청 선택 연도와 별개인 국내조달 파일 전체 기간의 기록 수다.

## 질병청 확인 근거와 한계

다음 공식 통계 페이지를 확인했다.

- [지역별 통계](https://dportal.kdca.go.kr/pot/is/rginEDW.do): 기간, 질병, 지역, 발생수/인구 10만 명당 발생률 선택 조건이 존재한다.
- [질병별 통계](https://dportal.kdca.go.kr/pot/is/inftnsdsEDW.do): 연도/월 등 조회 방식과 발생수/발생률 선택이 있다.
- [인플루엔자](https://dportal.kdca.go.kr/pot/is/st/influ.do)
- [급성호흡기감염증](https://dportal.kdca.go.kr/pot/is/st/ari.do)

공식 페이지의 현재 조건은 보관 CSV를 내려받은 당시 조건을 입증하지 않는다. 소수점 형식만으로 발생률 단위를 확정하거나, 다른 CSV의 질병 순서를 지역 수치 열에 그대로 붙일 수 없다. 원본의 지역명/등급/질병명/연도/절기 문자열만 식별 열 표시명으로 정리했고, 모든 수치와 빈 셀을 그대로 보존했다. 이는 원래 열 제목을 복원했다는 뜻이 아니다.

남은 해결 조건: 다운로드 당시 조회 기간·단위·질병 선택과 열 제목이 함께 있는 원본 XLSX/CSV 또는 화면 캡처가 필요하다. 해당 증거가 확보되기 전에는 통합 지표의 공통 기준일·단위 확인 항목을 통과시키지 않는다.

검증: 시도 별칭, 모호한 주소 미분류, 전체 기록 수 보존, 대구/경북 지역 연동, 질병청 원본 셀 보존을 자동 검사한다.

트리가드 전용으로 다시 구현하며 각 프로젝트의 모델·업무 알고리즘을 이식하지 않는다.

## 구현
- 배포 Git 커밋에 원본·검토 기록 링크를 고정. 보고서·자료 목록 CSV에 동일 버전을 기록.
- release_manifest.json에 배포 파일 SHA-256과 크기 기록. export 결과와 패키징된 기관 JSON을 독립적으로 대조.
- 기관 입력의 열 구조·필수 항목·계수 형식·중복 키를 검사. 미확인 질병청 메타데이터는 pending으로 유지.
- 기본 CSV 수치 열 검사와 지역 통계 양식 검사. 기록별 오류 사유·입력 파일 해시·전체 오류 CSV를 제공.
- 지역 통계 양식은 단일 통계 항목, 지역/연도/값/단위/출처 5열. 알려진 시도 이름과 1900–2100년, 명·건의 비음수 정수 조건을 검사. 출처 진위·공식 최신성을 보증하지 않음.
- 복사본 손상·중복·누락·비수치·메타데이터 상태를 검사하는 테스트와 실제 보고서 렌더러를 실행하는 원자료 대조 테스트.

## 한계
배포 시 파일 대조이지 외부기관 인증이 아니다. 보관 연구 결과의 과거 입력 파일 해시는 복구하지 않는다. 이미 배포된 공개 통계 조회·정적 연구 보관 범위이며 군사운용 엔진을 추가하지 않는다.

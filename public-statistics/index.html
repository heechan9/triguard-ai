    자료 출처와 해석

    01

    공개 통계 그대로

    2019–2025년 병역판정검사 원자료의 인원 수를 표시합니다. 원자료와 기존 연구용 통합 지표를 구분해 제공합니다.

    02

    자료 시점 확인

    저장소에 보관된 스냅샷이며 실시간 현황이 아닙니다.

    03

    관할 단위 확인

    지방청 관할 통계를 시·도 자체 통계로 해석하지 마세요. 지도는 지역 선택을 위한 탐색 도구입니다.

    원자료 대조 결과

    대조 결과는 자료를 불러온 뒤 확인합니다.

    검사 항목은 자료와 보고서를 확인한 뒤 표시합니다.

    배포 검사 보고서 JSON 다운로드

    이 표는 병역판정검사 자료의 배포 전 검사 기록입니다. 다시 확인 버튼은 보고서를 재조회하며 원자료 검사를 새로 실행하지 않습니다. 다른 기관 자료의 구조·메타데이터 상태는 해당 자료의 상세 안내를 확인하세요. 공식 정확성·최신성·장기간 가용성은 별도 검증 대상입니다.

    전체 자료 연결 현황

    원본 변경 기록을 불러오는 중입니다.

    병역판정검사 1종과 기관 자료 11종을 확인합니다. 같은 내용의 입영현황 파일은 한 번만 표시합니다. 해시 일치는 보관 원본과의 일치 확인이며 최신성 검증이 아닙니다.

    자료 연결 현황 CSV
    검사 결과를 어떻게 해석하나요?
    검사 통과
    정해진 구조·값·원본 대조 항목을 통과했다는 뜻입니다. 원자료의 공식 정확성, 최신성, 예측 성능까지 확인한 것은 아닙니다.
    보완 필요
    CSV 검토에서 기록 번호와 보완 사유를 확인하고 원자료를 수정한 뒤 다시 검사하세요. 빈 값을 임의로 0으로 채우지 마세요. 검사 통과만으로 다른 자료와 합산할 수 있는 것은 아닙니다.
    비교 전 확인
    지역 범위·기간·단위·항목 정의가 같은지 먼저 확인하세요. 업체 소재지와 납품 지역, 지방청 관할과 개별 시·도는 서로 다릅니다.
    품질과 장기 신뢰성
    이번 자료의 검사 결과와 장기간 서비스가 안정적으로 동작하는지는 별도입니다. 이 화면의 검사 결과를 서비스 가용률이나 장비 신뢰성 수치로 해석하지 마세요.

    결과를 설명하는 순서

    1. 무엇을 확인하려는지 질문과 대상 지역·기간을 적습니다.
    2. 사용한 출처·단위·자료 버전과 확인한 수치를 제시합니다.
    3. 검사한 범위, 발견한 문제와 수정 내용을 설명합니다.
    4. 자료만으로 판단할 수 없는 부분을 함께 적고 원문을 최종 확인합니다.

    자료 버전과 파일 목록은 위의 자료 연결 현황에서 확인할 수 있습니다.

    주요 용어와 자료 해석
    처분인원
    병역판정검사 처분 통계의 인원이며 실제 입영 인원과 다릅니다.
    면제자 관리현황
    별도 관리 통계로, 해당 연도 판정검사에서 면제된 인원과 구분합니다.
    대표업체 소재지
    계약 기록에 있는 업체 주소 기준이며 납품 장소를 뜻하지 않습니다.
    기존 연구 점수
    보관된 계산 결과입니다. 현재 자료로 재계산되지 않으며 실제 위험 확률이 아닙니다.
    빈 셀
    0건과 다릅니다. 출처에서 값이 없거나 확인되지 않은 항목입니다.
